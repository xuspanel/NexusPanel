We are excited to announce the official release of **NexusPanel v1.0** — a self-hosted, all-in-one VPS control panel for Linux servers.

## What is NexusPanel?

NexusPanel gives you complete control over your VPS from a single, beautiful web interface. Manage files, databases, Docker containers, domains, email accounts, firewall rules, and much more.

## Key Features

- **24+ built-in features** — everything you need to run a production VPS
- **One-command install** — get running in under 5 minutes
- **Dark/Light themes** — beautiful UI that works the way you want
- **License management** — secure your installation with license keys
- **Full API** — automate everything with REST endpoints

## Getting Started

```bash
bash <(curl -s https://raw.githubusercontent.com/xuspanel/NexusPanel/main/install.sh)
```

Visit [nxp.xus.me](https://nxp.xus.me) to get your license key and start managing your VPS today!
